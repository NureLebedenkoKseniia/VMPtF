Лебеденко Ксенія
ПЗПІ-23-9

1.6. Створіть простий відеохостинг. Користувач має мати можливість коментувати та
ставити. Прибирати лайки під відео.

2.6. Додайте можливість завантаження та перегляду відео. Реалізуйте систему
коментування відео.

3.6. Реалізуйте систему користувачів та управління їхніми правами. Додайте функціонал
"Поділитися відео", щоб користувачі могли надсилати відео іншим користувачам.

4.6. Оптимізуйте систему для високих навантажень. Реалізуйте систему підписки на
канали та повідомлень про нові відео.
